## 三、判断:`if` / `else if` / `else`

让程序"做选择"。基本形态:

```go
if 条件 {
	// 条件成立时做这些
} else if 另一个条件 {
	// 上面不成立、这个成立时做这些
} else {
	// 以上都不成立时做这些
}
```

判断要用到**比较运算符**:

| 符号 | 含义 |
|---|---|
| `>` `<` | 大于、小于 |
| `>=` `<=` | 大于等于、小于等于 |
| `==` | 等于(注意是**两个**等号!一个 `=` 是赋值) |
| `!=` | 不等于 |

> 新手高频错误:把"判断相等"写成 `=`(赋值),正确的是 `==`(两个等号)。

## 四、循环:`for`

Go 里**只有 `for` 一种循环**(没有 while),但它有几种用法:

```go
// 用法一:经典计数,从 0 数到 4,共 5 次
for i := 0; i < 5; i++ {
	fmt.Println(i)
}

// 用法二:只给条件(相当于别的语言的 while)
for count < 10 {
	count++
}

// 用法三:什么都不写 = 无限循环,必须靠 break 才能跳出
for {
	// 一直重复……
	break // 遇到 break 立刻跳出循环
}
```

猜数字游戏要"一直让你猜,直到猜对",所以用**用法三**(无限循环 + 猜对时 `break`)。

## 五、函数:把代码打包起来

**函数**就是把一段代码起个名字、打个包,以后想用就喊一声名字(叫"调用")。任务 1、2 里的 `main` 就是一个函数——程序从它开始跑。

自己定义函数的格式:

```go
func 函数名(参数) 返回值类型 {
	// 函数体
	return 要返回的值
}
```

例子:

```go
// 一个有"参数"和"返回值"的函数:传入两个整数,返回它们的和
func add(a int, b int) int {
	return a + b
}

sum := add(3, 5) // 调用它,sum 得到 8
```

**Go 的一个特色:函数可以返回多个值。** 这在后面非常常用(尤其是返回"结果 + 是否出错"):

```go
func divide(a int, b int) (int, bool) {
	if b == 0 {
		return 0, false // 除数为 0,失败
	}
	return a / b, true // 成功
}

result, ok := divide(10, 2) // result=5, ok=true
```

这个"多返回值"的写法,任务 4 处理错误时你会天天见到,先混个眼熟。

## 六、随机数:`math/rand`

让程序"想一个随机数",要用标准库的 `math/rand` 包:

```go
import "math/rand"

n := rand.Intn(100) // 返回一个 0~99 的随机整数
```

想要 1~100,就 `rand.Intn(100) + 1`。

> 小知识:老教程会让你先写一行 `rand.Seed(...)` 设置"随机种子",否则每次结果一样。**Go 1.20 以后不需要了**,直接用即可。

## 七、写代码

新建 `main.go`:

```go
package main

import (
	"fmt"
	"math/rand"
)

// 猜数字游戏:程序随机想一个 1~100 的数,你来猜,它提示大了还是小了。
func main() {
	// rand.Intn(100) 返回 0~99 的随机整数,+1 就变成 1~100。
	target := rand.Intn(100) + 1

	count := 0 // 记录猜了几次

	fmt.Println("我想好了一个 1 到 100 之间的数,你来猜!")

	// for 后面什么条件都不写,就是"无限循环",直到 break 才停下来。
	for {
		fmt.Print("请输入你猜的数:")
		guess := readInt() // 调用我们自己写的函数,读取一个整数

		count++ // 次数加 1

		if guess < target {
			fmt.Println("小了,再大一点!")
		} else if guess > target {
			fmt.Println("大了,再小一点!")
		} else {
			fmt.Printf("恭喜你猜对了!答案就是 %d,你一共猜了 %d 次。\n", target, count)
			break // 跳出循环,游戏结束
		}
	}
}

// readInt 读取用户输入的一个整数并返回。
func readInt() int {
	var n int
	fmt.Scanln(&n)
	return n
}
```

注意看顶部的 `import`:这次我们用了**两个**包(`fmt` 和 `math/rand`),所以用**小括号**把它们括在一起,一行一个。

## 九、(选学)用 `switch` 改写判断

`switch` 是 `if-else if` 链的另一种更清爽的写法:

```go
switch {
case guess < target:
	fmt.Println("小了,再大一点!")
case guess > target:
	fmt.Println("大了,再小一点!")
default:
	fmt.Println("猜对了!")
}
```

效果和 `if/else if/else` 一样,选你看着顺眼的用。
