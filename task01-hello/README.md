# 任务 1:第一个 Go 程序——打印、变量与输入

> 本任务目标:在电脑上跑起来你人生第一个 Go 程序,搞懂"写代码 → 运行 → 看到结果"这条最基本的链路,再让程序记住一点信息、和你简单对话。

---

## 一、先看看我们要做出什么

运行后,程序会先打印文字,再问你的名字和出生年份,最后算出你的大致年龄:

```text
你好,Go!
这是我的第一个 Go 程序,它会先打印文字,再和你简单聊两句。
请输入你的名字:小明
请输入你的出生年份(比如 2007):2007
你好,小明!
2007 年出生的你,今年大约 19 岁。
```

下面带冒号后面的 `小明`、`2007` 是你自己输入的内容。

## 五、第三步:写代码

新建 `main.go`,写入:

```go
package main

import "fmt"

func main() {
	fmt.Println("你好,Go!")
	fmt.Println("这是我的第一个 Go 程序,它会先打印文字,再和你简单聊两句。")

	const thisYear = 2026

	var name string
	fmt.Print("请输入你的名字:")
	fmt.Scanln(&name)

	var birthYear int
	fmt.Print("请输入你的出生年份(比如 2007):")
	fmt.Scanln(&birthYear)

	age := thisYear - birthYear

	fmt.Printf("你好,%s!\n", name)
	fmt.Printf("%d 年出生的你,今年大约 %d 岁。\n", birthYear, age)
}
```

别急着运行,先逐行看懂它。

## 六、这几行代码在干什么

| 代码 | 意思 |
|---|---|
| `package main` | 声明这是一个**可以独立运行**的程序。 |
| `import "fmt"` | 引入 `fmt` 包,用来打印文字、读取输入。 |
| `func main() { ... }` | 定义 `main` 函数。程序运行时,从这里开始执行。 |
| `fmt.Println(...)` | 打印一行文字,并自动换行。 |
| `const thisYear = 2026` | 定义常量。常量在程序运行期间不会改变。 |
| `var name string` | 定义变量 `name`,类型是字符串。 |
| `fmt.Scanln(&name)` | 读取你输入的一行内容,存进 `name`。 |
| `var birthYear int` | 定义变量 `birthYear`,类型是整数。 |
| `age := thisYear - birthYear` | 用简写方式定义变量 `age`,并计算年龄。 |
| `fmt.Printf(...)` | 按格式输出,可以把变量插进一句话里。 |

`&name` 里的 `&` 现在先记住一个直觉:

> `Scanln` 要知道"把输入放到哪里",所以我们把变量的位置交给它。

指针的细节后面会慢慢遇到,现在不用一次全懂。

## 七、Go 的几种基本类型

这次你已经用到了两种类型:

| 类型 | 例子 | 说明 |
|---|---|---|
| `string` | `"小明"` | 字符串,也就是一段文字。 |
| `int` | `2007` | 整数。 |

以后还会常见:

| 类型 | 例子 | 说明 |
|---|---|---|
| `float64` | `3.14` | 小数。 |
| `bool` | `true` / `false` | 布尔值,表示真或假。 |

变量就是一个有名字的盒子。类型决定这个盒子能放什么。

## 八、运行它

在 `task01-hello` 目录里运行:

```bash
go run .
```

`go run .` 的意思是"运行当前文件夹里的 Go 程序"。

如果输出和输入流程都正常,说明你已经完成了第一个 Go 程序。

---

## 九、`go run` 和 `go build` 的区别

现在运行:

```bash
go build
```

你会发现文件夹里多了一个可执行文件。Windows 上通常是:

```text
task01-hello.exe
```

区别很简单:

- **`go run .`**:编译并立刻运行,不留下可执行文件。适合开发时反复测试。
- **`go build`**:只编译,生成可执行文件。适合发给别人或部署。

## 十、重点讲讲 `Printf`

`Printf` 里的 `%` 开头的符号叫**占位符**,运行时会被后面的值替换:

| 占位符 | 用来放什么 |
|---|---|
| `%s` | 字符串 |
| `%d` | 整数 |
| `%f` | 小数 |
| `\n` | 换行 |

比如:

```go
fmt.Printf("你好,%s!\n", name)
```

如果 `name` 是 `小明`,输出就是:

```text
你好,小明!
```

## 十一、遇到报错怎么办

新手最常见的报错有这些:

### 1. 忘了引号

```go
fmt.Println(你好,Go!)
```

Go 会看不懂。文字必须放在英文双引号里:

```go
fmt.Println("你好,Go!")
```

### 2. 括号没有成对

```go
func main() {
	fmt.Println("你好")
```

少了最后一个 `}`。Go 里的 `{` 和 `}` 要成对出现。

### 3. 输入类型不对

如果程序问出生年份时,你输入了 `abc`,它没法把字母放进 `int` 变量里,年龄就会算错。

这次先知道问题存在。后面的任务会慢慢讲怎么更稳地处理错误。

完成这个任务,你已经知道:
