# Go 从零开始:九个任务 + 结业考核

这是一套面向**完全零基础**(比如刚高中毕业、没写过代码)的 Go 语言入门教程。

我们不按"语法书"那样一章讲变量、一章讲循环。我们用**九个能跑起来、看得见结果的小任务**带你入门——语法是为了做出东西而顺带学的。

学完你会拥有:
- 扎实的 Go 语言基础(变量、流程控制、函数、数据结构、结构体、错误处理)
- Go 的并发基础(goroutine、channel、context)
- 三个最常用的后端框架:**gin**(写 Web 服务)、**gorm**(操作数据库)、**viper**(管理配置)
- 一个能放进简历/GitHub 的完整待办(Todo)后端项目
- 一个结业考核项目:带用户系统的短链接服务

---

## 怎么用这套教程

1. **按顺序来**,从 `task01` 到 `task09`,每个任务都建立在前一个之上。
2. 每个任务是一个**独立文件夹**,里面有:
   - `README.md`:图文讲解(就是你正在读的这种)
   - 可以直接运行的 `.go` 代码
3. **一定要自己动手敲一遍**,不要只看。看懂和写出来是两回事。
4. 卡住了就把报错信息和代码丢给 AI 问——但要养成习惯:**看懂 AI 给的答案为什么对**,而不是复制完就走。这是 AI 时代最值钱的能力。

## 环境准备(只做一次)

### 1. 确认 Go 已经装好

打开终端(Windows 可以用 PowerShell、CMD,或 Git Bash),输入:

```bash
go version
```

如果显示类似 `go version go1.26.0 windows/amd64`,说明装好了,可以开始。

如果提示"找不到命令",去 https://go.dev/dl/ 下载安装,一路下一步即可,装完**重启终端**再试。

### 2. 什么是"终端"和"目录"

- **终端(Terminal)**:一个用打字来操作电脑的黑框框。我们运行 Go 程序都在这里敲命令。
- **目录(Directory)**:就是"文件夹"。命令 `cd 文件夹名` 表示"进入某个文件夹",`cd ..` 表示"返回上一层"。

这两个概念现在不用全懂,跟着第一个任务做一遍就会了。

## 九个任务一览

| # | 文件夹 | 你会做出什么 | 顺带学到 |
|---|---|---|---|
| 1 | `task01-hello` | 会打印、会提问的小程序 | 模块、`go run`/`build`、变量、类型、输入输出 |
| 2 | `task02-flow` | 猜数字游戏 | if / switch / for、函数 |
| 3 | `task03-collection` | 词频统计 / 通讯录雏形 | slice、map、字符串 |
| 4 | `task04-struct` | 通讯录重构 | 结构体、方法、错误处理 |
| 5 | `task05-http` | 调用一个网络 API | JSON、HTTP 请求 |
| 6 | `task06-concurrency` | 同时处理多个任务 | goroutine、channel、context |
| 7 | `task07-gin` | 待办事项 Web API | gin 框架 |
| 8 | `task08-gorm` | 让数据存进数据库 | gorm + SQLite |
| 9 | `task09-viper` | 完整可配置的后端服务 | viper、项目分层、测试 |

> 第 5、9 个任务里有**可选的 AI 小练习**(调用大模型),不想做可以跳过,不影响主线。

## 一键检查

如果你想确认 1–9 的代码都能编译、测试能通过,可以在根目录运行:

```powershell
powershell -ExecutionPolicy Bypass -File .\check.ps1
```

它会依次进入每个任务目录执行 `go test .`。
